# 🩺 PediaCare.AI — Interactive Clinical Decision Support Demo

عرض توضيحي حي وتفاعلي شامل لنظام **PediaCare.AI** (المساعد السريري الذكي لطب الأطفال المبني على إرشادات منظمة الصحة العالمية WHO IMCI).

---

## 🌟 محتويات وميزات الديمو التفاعلي

1. **محطة عمل الطبيب السريرية (Doctor Workstation):**
   - استعراض بروتوكولات منظمة الصحة العالمية الثمانية (WHO IMCI Guidelines) مع المعايير والإجراءات الفورية وأرقام الصفحات الرسمية.
   - حاسبة مقياس الإنذار المبكر للأطفال (**PEWS Interactive Calculator**) مع تصنيف لوني فوري لمستوى الخطورة (🔴/🟡/🟢).
   - حاسبة الجرعات بالمحاقن الذكية المتحركة (**Animated Syringe Visualizer**) للأموكسيسيلين، الباراسيتامول، الزنك، وفيتامين أ.
   - حاسبة إنعاش الجفاف الشديد وريدياً (**Plan C IV Resuscitation**) مع **بندول تنقيط صوتي وبصري تفاعلي (Audio Metronome)** مبني بـ Web Audio API.
   - عداد سرعة التنفس التفاعلي (**Respiratory Rate Counter**) مع محاكاة بصرية لنبض الرئتين ومؤقت تنازلي 60 ثانية ومقارنة فورية بعتبات العمر.
   - توليد التقرير السريري ورمز الاستجابة السريعة (**QR Code & Printable Summary**).

2. **محادثة ولي الأمر الذكية (Parent Smart Chat):**
   - محاكاة المحادثة الذكية التفاعلية مع دعم الحالات السريرية الجاهزة.
   - محاكاة التسجيل الصوتي وتوليد بطاقات الفرز اللوني الفورية.
   - إرشادات الرعاية المنزلية وعلامات الخطورة التي تستوجب العودة الفورية.

3. **مستكشف الأدلة والـ RAG (Evidence & Cosine Similarity Inspector):**
   - فحص المقاطع المسترجعة من دليل الـ 142 صفحة مع قياس نسبة التطابق الدلالي (**Cosine Similarity %**).
   - اختبار مصد الأمان السريري (**Clinical Safety Threshold Gate**) عند 43.5% لرفض حالات البالغين وأمراض القلب.

4. **الخط الزمني وسجل الحالات (Symptom Timeline):**
   - تتبع تطور المرض واستجابة الطفل للعلاج على مدار الأيام.

5. **لوحة الاختبارات المعيارية (Clinical Benchmark Suite):**
   - تقييم 5 حالات اختبار سريرية مع قياس زمن الاستجابة ونسب التطابق وحالة المصدات.

6. **الهيكل المعماري والتبديل التلقائي (Zero-Downtime Multi-Model Fallback):**
   - توضيح مسار فحص الأمان الثلاثي (Check 1, Check 2, Check 3) والتبديل بين Gemini 3.5 / 3.7 / 3.1 والمحرك المحلي.

7. **جولة تعليمية تفاعلية (Interactive Guided Tour):**
   - نافذة استرشادية تأخذ المستخدم خطوة بخطوة لشرح كافة إمكانيات النظام.

8. **دعم ثنائي اللغة (العربية / English):**
   - تبديل فوري بين العربية والإنجليزية مع تعديل اتجاه الواجهة (RTL / LTR).

## 🎬 فيديو العرض التقديمي السينمائي (PowerPoint Video Showcase)

تم تصميم صفحة عرض سينمائية مستقلة **`demo/video_presentation.html`** مطابقة بدقة للمخطط الزمني لمونتاج الفيديو الترويجي (60 - 75 ثانية) بأسلوب عروض جوجل الإعلانية:

* **0:00 - 0:08 | The Hook & Dual Persona:** موك آب ثلاثي الأبعاد يدخل بانسيابية (3D Tilt) مع استعراض واجهة اختيار الدور (Parent vs Clinician).
* **0:08 - 0:25 | AI Triage & Local Engine:** فحص الطفل "زياد" مع اختيار الشيبس السريعة (كحة وضيق تنفس) وظهور شارة المحرك المحلي (Offline IMCI Engine) وتصنيف الحالة باللون الأحمر.
* **0:25 - 0:40 | Evidence Grounding & SBAR:** التوثيق الطبي المعتمد مع رقم الصفحة (Page 23) وتقريب الكاميرا على توليد رمز الـ QR Code الذكي للطوارئ.
* **0:40 - 0:60 | Clinician Power Tools:** تشغيل محقنة الجرعات الذكية، نبضات محلول الجفاف الوريدي مع المترونوم الصوتي، وتصاعد مؤشر PEWS للأحمر الناري (6/9).
* **0:60 - 0:70 | Outro & Key Value:** رجوع الكاميرا للخلف وعرض الشاشات المتعددة في فضاء ثلاثي الأبعاد مع الشعار والرسالة الختامية.

## 🚀 كيفية تشغيل الديمو وعرض الفيديو

### 1. عبر المتصفح مباشرة:
* لوحة التحكم التفاعلية: **[http://localhost:3000/](http://localhost:3000/)**
* فيديو العرض السينمائي (60-75s): **[http://localhost:3000/video_presentation.html](http://localhost:3000/video_presentation.html)**

### 2. إدراج العرض في شرائح PowerPoint:
* يمكنك فتح صفحة `video_presentation.html` في وضع ملء الشاشة (F11 أو زر ملء الشاشة) وتشغيل العرض التلقائي أثناء إلقاء العرض التقديمي.
* أو تسجيل الشاشة بجودة 1080p عبر أداة تسجيل الشاشة (Windows Game Bar / OBS) وإدراج ملف الفيديو مباشرة داخل شريحة PowerPoint كـ Video.
